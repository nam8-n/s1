# 신입생 기초학력 진단평가 시범 프로그램 (프로토타입)

2027학년도 간소화 기획서(과목당 15문항·20분·중2~3 수준, 수리 공통10+계열별 응용5, 국어·영어 독해10+지시문5 공통, 낙인 없는 3트랙 추천)를 구현한 정적 웹 프로토타입입니다.

## 실행
```bash
cd diag && python3 -m http.server 8000   # 브라우저: http://localhost:8000  (관리자: #admin, PIN은 data.js)
```
## 구성
- `data.js`: 설정(PIN·컷오프·학과→계열·트랙 프로그램)과 **샘플 문항**(실제 문항으로 교체 필요)
- `app.js`: 응시(타이머·자동제출)·자동채점·영역별 환류·추천 트랙·관리자 현황/CSV
## 한계(운영 전 필요 사항)
- 데이터는 브라우저 localStorage에만 저장 → 서버·DB 필요, 정답이 클라이언트에 노출됨 → 서버 채점 필요
- 관리자 PIN은 시범용 → 학교 계정(SSO) 연동 필요
- 개인정보(학번·이름·성적) 수집·이용 동의 및 보관 기간 정책 필요
- 문항 샘플 55개는 검수 전이며, 컷오프(50/80%)는 파일럿 후 확정

## 수리 문항은행 (4개 계열 × 4세트 × 15문항)
- `items_math.js`(생성물), 생성·검증기 `tools/gen_math_nature.py`(`python3 tools/gen_math_nature.py`), 검토용 `docs/수리_*_60문항.(docx|md|csv)`
- 1~10번(공통)은 전 계열 동일, 11~15번(응용)은 계열별. 세트당 기초 11·표준 3·변별 1. 학번 기준 A~D 세트 자동 배정.

## 국어·영어 문항은행 (전 학과 공통, 과목당 4세트 × 15문항)
- `items_lang.js`(생성물), 생성·검증기 `tools/gen_lang_bank.py`, 검토용 `docs/국어_공통_60문항.*`, `docs/영어_공통_60문항.*`
- 세트당 독해 10(지문 2개×5문항) + 지시문 이해 5, 기초 11·표준 3·변별 1. 독해 지문 5문장 이내, 부정형 문제는 밑줄.
