문제해결 프로젝트 도우미

「미래사회와 문제해결능력」 팀 프로젝트를 쓰다가 막힐 때 물어보세요. 5Why, 로직트리, SCAMPER, 악마의 주장법을 어떻게 적용할지 질문으로 함께 풀어 줍니다. 보고서를 대신 써 주지는 않습니다.

사용 설명서 (처음이라면 눌러서 읽어 보세요)

이렇게 사용하세요

  1. 아래 입력칸에 질문을 쓰고 보내기를 누릅니다. 줄바꿈은 Shift+Enter입니다.
  2. 처음 보내면 Claude 사용 허용 창이 뜹니다. 허용해야 대화할 수 있습니다.
  3. 오른쪽(모바일은 아래쪽) 기법 빠른 안내에서 항목을 누르면 질문 문장이 입력칸에 채워집니다. 팀 주제를 덧붙여 보내세요.
  4. 답변이 마음에 들지 않으면 "더 쉽게 설명해 주세요", "예시를 하나 더 보여 주세요"처럼 이어서 물어보세요.
  5. 답변이 길면 중지를 누를 수 있고, 처음부터 다시 하려면 새 대화를 누릅니다.

이렇게 물으면 더 잘 도와줘요

팀 주제, 막힌 곳, 지금까지 해 본 것을 함께 쓰세요.

이런 질문에 쓰세요

  • 5Why, 로직트리, SCAMPER, 악마의 주장법을 어떻게 적용하는지
  • 보고서에 무엇이 들어가야 하는지(필수 요소, 분량, 구성)
  • 쓴 내용이 루브릭 기준에 맞는지 점검
  • 통계와 근거 자료를 어디서 찾는지

도우미가 하지 않는 것

  • 보고서나 해결안을 대신 써 주지 않습니다. 개념, 틀, 질문으로 돕습니다.
  • 점수나 합격 여부는 알려 주지 않습니다.
  • 통계 수치를 지어내지 않습니다. 수치와 출처는 직접 찾아 확인하세요.
  • 과제와 관계없는 질문에는 답하지 않을 수 있습니다.

알아 두세요

  • AI라서 틀린 설명을 할 수 있습니다. 과제 기준은 강의계획서와 교수님 안내가 우선입니다.
  • 대화 내용은 이 브라우저에만 저장되고, 교수님에게 전달되지 않습니다.
  • 질문은 지금 로그인한 본인 Claude 계정의 사용량으로 처리됩니다.
  • "요청이 많아요"가 뜨면 잠시 뒤에 다시 보내세요.
