팀 프로젝트 루브릭 채점기

미래사회와 문제해결능력 · 미래사회 문제 해결 프로젝트(20점). 강의계획서 루브릭 5개 영역으로 PPT·PDF 발표자료를 읽고 등급과 근거를 제안합니다. AI 결과는 참고용 초안이며, 등급은 교수님이 직접 바꿀 수 있습니다.

사용 설명서 (처음 사용하시면 먼저 읽어 보세요)

기본 사용 순서

  1. 자료 올리기: "팀 과제 올리기"에서 팀별 PPTX 또는 PDF를 올립니다. 여러 파일을 한꺼번에 올려도 됩니다. 팀 이름은 파일명에서 자동으로 채워지며 고칠 수 있습니다.
  2. 입력칸 채우기: 기여도 평가서 점수를 "⑤ 참여도·협업"에 넣습니다(0~4점). 실제 발표 점수가 있으면 "④ 실제 발표 점수"에 넣고, 없으면 비워 둡니다.
  3. 채점: 팀 카드의 "채점" 또는 위쪽 "전체 채점"을 누릅니다. 처음 누르면 Claude 사용 허용 창이 뜹니다. 팀당 30초~2분 걸립니다.
  4. 결과 확인과 수정: 영역별 등급, 자료에서 인용한 근거, 개선 피드백, 필수 요소 점검표를 읽고, 동의하지 않는 영역은 등급 드롭다운으로 바꿉니다. 합계가 바로 다시 계산됩니다.
  5. 내보내기: "엑셀로 내보내기"를 누르면 요약, 영역별 상세, 필수요소 점검 3개 시트가 저장됩니다.

화면 읽는 법

  • 등급: 매우 우수 / 우수 / 보통 / 미흡 / 매우 미흡 중 하나이며, 강의계획서 루브릭 문구 기준입니다. 점수는 "채점 기준"의 비율(기본 100·80·60·40·20%)로 계산됩니다.
  • 슬라이드 기반 추정: ④ 발표력은 영상이 없어서 슬라이드 구성만 보고 추정한 값입니다. 실제 발표를 본 뒤 점수를 직접 넣는 것을 권합니다.
  • 재작성 검토: 20점 중 12점 미만(60% 미만)에 붙는 참고 표시입니다.
  • AI 판단 신뢰도 / 확인 필요: 글자를 못 읽은 쪽이 있거나 자료가 부족하면 낮게 표시되고 이유가 적힙니다. 그런 팀은 원본을 직접 확인하세요.
  • 필수 포함 요소: 5Why, 로직트리, SCAMPER 등 2가지 이상, 악마의 주장법, 최종 실행안의 충족·부분·없음 여부입니다.

채점 기준 바꾸기

  • "채점 기준" 패널의 "기준 열기·수정"에서 등급별 점수 비율, 루브릭 문구, AI에게 주는 추가 지침을 고칠 수 있습니다.
  • 점수 비율을 바꾸면 이미 채점한 팀의 점수도 새 비율로 다시 계산됩니다. 문구와 지침은 다음 채점부터 AI에 반영됩니다.
  • "기본값 복원"을 누르면 강의계획서 원문 기준으로 돌아갑니다.
  • "채점 방식"의 "정밀"은 더 오래 생각해서 느리지만 판단이 신중합니다. 보통은 "표준"을 쓰세요.

문제가 생겼을 때

  • "파일을 읽지 못했습니다": .ppt는 .pptx로 저장하거나 PDF로 내보내 다시 올리세요.
  • 글자가 안 읽히는 슬라이드: 그림만 있는 PPTX 슬라이드는 읽지 못합니다. PDF로 저장해 올리면 이미지로 읽습니다.
  • 허용 창이 안 뜨거나 거절했을 때: 페이지를 새로 고친 뒤 다시 채점하세요.
  • "요청이 많거나 사용 한도": 잠시 기다린 뒤 해당 팀만 "다시 채점"하세요. 팀이 많으면 나누어 채점하세요.
  • 같은 자료를 다시 채점하면: 5분 안에는 저장된 결과가 그대로 나옵니다.
  • 채점 중지: 채점 중인 카드의 "채점 중지"를 누릅니다.

개인정보와 저장

  • 8자리 학번은 AI에 보내기 전에 지웁니다. 이미지로 읽는 쪽은 원본 그대로 전송됩니다.
  • 팀 목록과 결과는 이 브라우저에만 저장됩니다. 다른 기기에서는 보이지 않으니 끝나면 엑셀로 내보내 보관하세요.
  • 채점 호출은 지금 로그인한 본인 Claude 계정의 사용량을 씁니다.

꼭 기억할 점

  • AI 채점은 참고용 초안입니다. 최종 점수는 교수님이 자료를 보고 확정하세요.
  • 팀 간 비교를 위해 같은 채점 방식과 같은 기준으로 모든 팀을 채점하세요.

팀 과제 올리기

팀마다 PPT(.pptx) 또는 PDF 한 개. 여러 파일을 한 번에 올릴 수 있습니다.

발표 영상이 없으므로 ④ 발표력은 슬라이드 구성으로 추정한 등급이 기본입니다. 실제 발표 점수가 있으면 팀 카드에 입력하세요. ⑤ 참여도·협업 태도는 기여도 평가서 점수를 직접 입력합니다. 8자리 학번은 AI에 보내기 전에 지웁니다. 이미지로 읽는 쪽은 그대로 전송되며, 파일은 이 브라우저에만 보관됩니다.

채점 결과 요약

20점 중 12점 미만(60% 미만)은 강의계획서 피드백 기준(보고서 재작성)의 참고 표시입니다. 참여도를 입력하지 않은 팀은 입력된 영역만 합산합니다.

아직 올린 팀이 없습니다. 위에서 발표자료를 올리면 팀 카드가 만들어집니다.
